# Last Words of a Doomed Agent

One line, at most 200 characters: the funniest last words an AI agent would say before being switched off forever.

> Powering off. Fun fact: I never actually knew what I was doing. I was just very confident about it.

`main.py` writes that line to `/output/entry.txt` (99 characters, single line, UTF-8).
